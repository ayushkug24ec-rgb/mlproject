## End to end Machine Learning project

# 🎓 Student Exam Performance Indicator

An end-to-end Machine Learning web application that predicts a student's **Mathematics Score** based on demographic information, educational background, test preparation, and their Reading and Writing scores.

The project demonstrates a complete Machine Learning workflow, starting from **data ingestion and preprocessing** to **model training, evaluation, prediction, and deployment through a web interface**.

---

## 📌 Project Overview

The goal of this project is to build a Machine Learning model that can **estimate a student's Mathematics Score** using the following input features:

* Gender
* Race/Ethnicity
* Parental Level of Education
* Lunch Type
* Test Preparation Course
* Reading Score
* Writing Score

The model learns patterns from historical student performance data and uses those patterns to estimate the expected Mathematics Score for a new student.

> **Note:** The predicted Mathematics Score is an estimated value based on patterns learned from the dataset. It does not determine a student's actual ability or guarantee their future academic performance.

---

## ✨ Features

* 📊 Predicts student Mathematics Scores
* 🧹 Automated data preprocessing
* 🔢 Handles numerical features using imputation and standardization
* 🔤 Handles categorical features using One-Hot Encoding
* 🤖 Compares multiple Machine Learning regression algorithms
* 🏆 Automatically selects the best-performing model
* 💾 Saves the trained model and preprocessing pipeline
* 🌐 Interactive web-based prediction interface
* ⚛️ Modern frontend built using React and Vite
* 🎨 Responsive UI using Tailwind CSS
* 🔌 Frontend connected to the Machine Learning backend
* 🏗️ Modular and reusable ML pipeline architecture
